This build

What is and is not in the tab.

In

The language, the standard library, the in-house regular-expression engine, Intl, Temporal, and BigInt. That is {{ build.gzip }} over the wire — about {{ build.intlShare }} of it is Unicode and CLDR data, which is what makes Intl and the non-ISO calendars work.

Out

The host runtime: no fetch, no file system, no real timers. Bare WebAssembly also has no clock, so Date.now() reads 0 here — that is this build, not the engine.

Runaway scripts

A running WebAssembly instance cannot be interrupted, so the engine lives in a worker with a {{ build.timeout }} budget. Write for (;;) {} and the worker is replaced, not the tab.
